# Macaron E-Commerce Demo

A macaron-themed e-commerce demo site built with Next.js.

This project is currently under development and **not intended for production use**.

## 🚧 Notice

**This is a demo site.**  
Please do not attempt to place real orders or submit payments.

---

## 🔧 Features Implemented

- Basic site layout using reusable components
- Navigation bar with routing to ancillary pages
- Demo banner for user communication
- Static pages: About, Contact, Terms, Privacy, Delivery
- Footer with navigation links and placeholder payment icons
- Placeholder contact form

## 🚀 Getting Started

1. Clone the repo
2. Navigate to the project folder
3. Install dependencies: ```npm install```
4. Start the development server: ```npm run dev```
5. Visit `http://localhost:3000` in your browser
